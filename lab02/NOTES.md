Рабочая папка это просто папка с проектом на компе, где ты прямо сейчас пишешь и меняешь код. Индекс это типа черновик, куда ты добавляешь файлы, которые хочешь сохранить, чтобы в историю не попал случайный мусор. Коммит это уже готовый снимок этих изменений, который навсегда сохраняется в истории гита с твоим сообщением о том, что именно ты сделал.

Гит это программа на твоем компе, которая следит за версиями кода и сохраняет изменения. А Гитхаб это сайт в интернете, куда ты загружаешь свой проект, чтобы сделать бэкап или работать над ним вместе с друзьями. Гит работает у тебя локально, а Гитхаб это просто облачный хостинг для твоих репозиториев.

git status выводит статус файлов, показывая что изменено, что уже в индексе и что не отслеживается
git diff показывает разницу между рабочими файлами и индексом, то есть какие правки еще не добавлены
git diff с параметром staged показывает разницу между индексом и последним коммитом, то есть что именно попадет в следующий коммит
